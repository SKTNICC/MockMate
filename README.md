# MockMate

面向个人材料的面试准备 Android App。技术栈：**Kotlin / Jetpack Compose + FastAPI + PostgreSQL**。

当前阶段是 **M2：文字模拟面试**。已实现账户、简历/JD材料核对、匹配、题库/AI来源严格各半的计划、确认保存与重新打开；M2 新增从已确认计划开始正式文字面试、逐题作答、最多一次追问、跳过/暂停/续答/提前结束、面后评分报告与面试记录重开。**M1 尚未整体验收通过，M2 也尚未完成真实模型、真实审核内容和真实手机组合验收，当前不是正式上线版本。**

## 当前状态

后端是已实现的真实FastAPI服务，数据持久化到PostgreSQL；Android通过HTTP访问。当前测试流程的AI使用`test` provider和合成题库，尚未接入并验证真实模型与真实双人审核内容。

最近独立验证：后端**192项测试**、Android**72项JVM单测**、debug构建、契约生成一致性和地基检查通过；M2 六题合成 HTTP 冒烟 47 项检查通过，旧计划升级迁移验证通过。它们不能替代真实AI、人工审核和完整真机验收。

仍需修复/验证材料写回页面隔离U01；真实IME选词、系统文件选择、A/B迟到手机证据尚不完整。详见[工程进度](docs/overview/工程进度.md)。M3–M6的语音/视频、专项练习和长期能力画像未实现。

## 目录

| 目录 | 内容 |
|---|---|
| `android/` | Compose客户端、加密存储、操作恢复、轮询、JVM和设备测试 |
| `backend/` | API、模型、迁移、worker、AI adapter和测试 |
| `contracts/m1/` | 生成的OpenAPI与JSON Schema |
| `fixtures/m1/` | 明确标识的合成样例、测试题库、目录与规则向量 |
| `tools/m1/` | 契约维护源、检查器和隔离设备测试辅助工具 |
| `docs/` | 文档目录索引、文档规范、项目总览与各里程碑交付/整改文档 |

共享契约先修改`tools/m1/build_contracts.py`，再生成并同步两端，不只修改JSON生成物。

## 数据与发布范围

本仓库发布实现代码、必要构建配置、合成测试数据及上述说明。真实`.env`、Key/token、私人简历/JD、数据库、原始上传文件、APK、截图/运行日志、本机缓存、历史调研、下载的第三方仓库和许可待确认的正式内容均不纳入本次发布。

`test_only`和`synthetic_test`审核仅用于测试，不是真实人工批准。生产环境禁止测试fixture；未审核内容不能用于生产选题。服务端独立执行材料门槛、所有权、版本、审核、配额、去重和评价依据校验。

本次上传是开发基线归档，没有执行正式部署，也没有新增项目许可证。
