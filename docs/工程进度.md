# MockMate 已开发内容与工程进度

更新：2026-11-17。本文件对应当前公开源码基线，不是生产上线或M1验收通过声明。

## 1. 当前结论

**已具备可运行的Android客户端、真实FastAPI后端和PostgreSQL持久化，但M1尚未整体通过。** 当前暂停功能扩展，先归档实现与验证状态。

“模拟”主要指测试流程里的AI输出、合成材料和合成审核数据，整个后端并不是mock。API、数据库、任务worker、幂等和业务校验是真实实现；真实模型和真实审核内容还没有完成组合验证。

M1目标：用户登录后核对本人简历和JD，查看有证据的匹配，获得题库/AI来源严格各半且不重复的个性化计划，确认保存，退出或杀进程后重新打开同一个计划。当前终点是计划准备完成，未实现正式面试开始、回答或评分报告。

## 2. 技术与结构

```text
Android Compose → ViewModel / Repository → HTTP /v1
                                        ↓
                                FastAPI / services
                                  ↓            ↓
                             PostgreSQL     私有文件目录
                                  ↑
                       独立worker → AI provider
```

| 部分 | 技术与入口 |
|---|---|
| Android | Kotlin2.0.21、Compose、Ktor；`android/app/src/main/` |
| API | FastAPI、Pydantic；`backend/app/main.py`、`app/api/` |
| 数据 | SQLAlchemy + psycopg + PostgreSQL；`app/models.py` |
| 迁移 | Alembic，当前head `9b2c3d4e5f6a` |
| 后台任务 | `backend/app/workers/runner.py`，独立进程 |
| AI | provider协议、DeepSeek adapter、`test` provider；`backend/app/ai/` |
| 契约 | `contracts/m1/`；维护源`tools/m1/build_contracts.py` |

工程基线为2/4/6题、默认6题；Java后端实习仅是开发样板。这些不是已经逐项确认的最终产品参数，也不代表大规模岗位内容已经准备完成。

## 5. 已知问题与未完成项

### U01：材料写回页面隔离

**静态调用链确认，尚未动态复现或修复。** `AppViewModel.saveTextMaterial/uploadFile/confirmProfile`部分回包后只检查账号，用户返回或切到另一准备后，旧请求仍可能跳回原材料页、覆盖全局材料/提示，或清掉新草稿。job恢复的scope闸门不能自动保护这些普通写操作。

下一步应先补实际材料写入调用链的失败回归，再在UI副作用前校验原账号/会话/导航/对象与版本。服务器合法成功和是否允许改变当前页面要分开，不能通过换key、禁止返回或丢记录解决。

### 手机尚缺的证据

- 真实拼音组合/选词及保存重开。已观察IME，但安全窗口下最终候选提交未核验；可由负责人完成一次选词，收起键盘后核对App结果，不绕过安全保护。
- 系统OpenDocument选择TXT/PDF/DOCX、URI实际读取、取消、同摘要重选恢复、不同内容不误复用，以及上传迟到切页。
- A→B手机迟到回包。现有P1→P2设备记录不能代替跨账号场景；组件测试和正常换号也不能代替。

### 真实AI和正式内容

- 尚需负责人配置服务端真实provider/模型/凭据并明确测试调用授权与额度。
- 尚需来源使用许可和两位不同真实审核者，对最终内容版本/digest填写ledger。当前没有真实审核批准，不由编码模型代签。
- 需要在同一固定候选上完成真实AI+真实已审内容+手机确认/冷启重开的组合出口。

### 工程交付边界

尚未完成正式服务器部署、生产HTTPS端点/签名/发布验证。Docker/Compose为未实测开发脚手架，当前镜像的仓库级fixture路径仍需部署适配。本地集成测试固定使用55432端口和独立`mockmate_test`库，不可直接指向共享或生产实例。
