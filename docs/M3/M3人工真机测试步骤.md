# M3 人工真机测试步骤

> 更新日期：2026-11-20 ｜ 状态：待负责人实际操作与记录 ｜ 设备：PCAM00 / `<device-serial>` ｜ 适用阶段：M3 ｜ 候选：已安装 app `10B9266C…` ｜ 配套：[模型执行方案](M3人工验收与最终交付方案.md)

## 1. 开始前

本轮已恢复电脑API和worker、关闭调试录音fixture、建立8000端口转发。请保持电脑开机、手机USB连接并解锁；重连USB或电脑休眠后，让协助模型重新检查服务和端口转发。不要卸载App或清除数据。

打开MockMate，登录你自己的账号。自动测试账号可能来自已删除的测试库，登录失效时正常退出并重新登录即可。请让模型确认你账号下有一个已确认、尚未使用的6题虚构计划，显示“3题库＋3生成”。没有计划时由模型帮助准备，不要借用其他账号的计划。

真人测试会调用真实DeepSeek：仅一场、总计最多40次尝试，失败/重试/准备都算。请先让协助模型开始记录，再进入语音场；不要连续点重试或反复生成计划。若页面仍显示“当前录音来自调试fixture”，立即停止，让模型关闭它，不能继续算真人测试。

## 2. 先验证麦克风权限

1. 长按MockMate图标，打开“应用信息”，进入“权限→麦克风”，设为拒绝。系统菜单名称可能略有不同，不要点“清除数据”。
2. 回App，进入待回答的语音题，点击“开始录音”。拒绝系统授权提示。应明确提示没有麦克风权限，不出现假录音、不提交答案或跳题。
3. 回同一权限页面改为允许，再打开App回到原场。录音应恢复可用。系统若因撤权关闭App，重新打开即可。
4. 告诉模型拒绝时的提示、允许后能否录音。设备命令撤权不受支持不影响你手动完成这一步。

## 3. 完成真人六题

1. 进入已确认的6题计划，选择语音面试并同意音频说明；确认“语音场”和题目来源3+3。本人已有原场时继续原场，不重复开场。
2. 听完题目，点“开始录音（最多120秒）”，用自己的话回答，建议每题20–40秒；例子可用虚构项目，不说真实个人资料。
3. 点“停止录音（不自动提交）”，等转写完成。核对页应是你刚才说的话，随后才点“确认提交”。停止按钮会继续上传/转写，不等于答案已提交。
4. **至少一题重录**：第一次转写完成后点“重录本题”，说一句明显不同的内容，例如“这是重录后的第二段回答”，停止并核对。最终提交应来自第二段，不应显示第一段或卡在上传。
5. **另一题修改核对文本**：修正一个识别错误，或加入“本次为测试回答”。若显示保存失败，先用“重试保存核对修改”，不要当作保存成功。可以先返回再进入或切后台再回来，确认修改仍在，再点“确认提交（人工核对文本）”。
6. 有追问就正常回答；完成6个主问后等报告，不用“跳过本题”或“提前结束”替代整场。
7. 打开报告，找修改过的那题，确认答案和来源正确；退出后从面试历史再打开，仍应是同一份报告。

## 4. 耳机、来电与后台

在同场尚未提交的题目中与模型约定时机，逐项做：

| 操作 | 请观察并反馈 |
|---|---|
| 播题时拔/插耳机一次，再手动重播 | 声音从哪里播放、有无突然外放、是否停止或提示、重播是否正常；不要凭“能出声”直接记通过 |
| 播题时让另一部手机呼入一次 | 播放是否中断，结束后能否回原题显式重播，有无自动录音/提交 |
| 录音几秒后呼入一次 | 录音是否停止/提示中断；通话结束后原题和片段是否可恢复；不应把通话继续录入或自动提交 |
| 核对文字未提交时切后台约10秒再回来，旋转一次 | 修改是否保留、有没有重复上传、跳题或重复提交 |

真实来电需要另一部电话；没有耳机/来电条件就明确记“未执行”，不要用播放音乐代替来电。媒体中断若导致无法继续，停在当前页面报告现象，避免连续重录把问题覆盖掉。

## 5. 断网与120秒

真实120秒上限已有真机自动测试证据，不改录音实现时不要求你再等两分钟。你若自愿复测，保持前台录音到倒计时结束，应该停止采集、保存并进入转写核对，不自动确认答案。

USB转发不走手机Wi-Fi。**仅切手机Wi-Fi/飞行模式不算App与电脑断网测试。** 这一项由模型安排隔离通路故障；若需要你拔USB，它应先说明时机，接回后由它重新建立转发并确认恢复。不要在无协助时随机拔线后反复点提交。

## 6. 反馈模板

完成一项即可反馈，不必等全部完成。问题截图避免出现真实个人材料，不发送API Key或密码。模型再核对任务、来源与报告，决定该项是否通过。

```text

大约时间：
第几个主问或追问：
我做的动作：
页面提示或异常原文：
能否继续原场：
截图：有 / 无
```

真人测试完成仍不等于A25正式内容已审核。正式来源许可和两名真实审核者另行完成，由模型更新最终验收记录。
