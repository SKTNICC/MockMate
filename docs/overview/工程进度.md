## 1. 当前结论

项目已有可运行的 Kotlin/Compose Android 客户端、真实 FastAPI 后端、PostgreSQL持久化和独立worker。M1面试准备、M2文字模拟面试、M3按回合语音面试均已有实现；M4视频、专项练习和长期画像未实现。

**M3工程修复通过最新独立复查，最终验收仍未通过。** 真人实际听题和回答的真实模型六题整场、耳机/来电、权限撤销、剩余设备恢复矩阵，以及正式内容许可和双人审核尚未完成。

本次commit按负责人要求包含“**m3阶段 未真机实测**”。该标记表示完整真人真机验收尚未完成；历史已有真机自动化、物理麦克风声学回路及120秒录音证据。下文分别记录具体层级，源码归档本身不计作新增设备验收。

后端不是整体模拟：API、数据库、任务、事务、所有权和幂等均为真实实现；自动化回归中的test provider、合成材料/题库、fixture PCM和本地HTTP/WS桩属于测试替身。真实DeepSeek文字/ASR/TTS已有受控小样本成功记录，尚未完成正式内容与真人整场的组合验收。

## 2. 技术与结构

```text
Android Compose → Repository / HTTP /v1 → FastAPI / services
                                              ↓
                                    PostgreSQL + 私有文件
                                              ↑
                                  独立worker → 文字/语音provider
```

| 部分 | 技术与入口 |
|---|---|
| Android | Kotlin2.0.21、Compose、Ktor2.3.12；`android/app/src/` |
| API/数据 | FastAPI0.115.6、Pydantic2.10.4、SQLAlchemy2.0.36、psycopg3.2.3；`backend/app/` |
| 迁移 | Alembic1.14.0，单一head `c3d4e5f6a7b8`；`backend/alembic/versions/` |
| 任务/模型 | `app/workers/runner.py`；文字`app/ai/provider.py`、语音`app/ai/speech.py`，disabled/test/deepseek明确配置 |
| 契约 | `tools/m1/build_contracts.py`为维护源；生成`contracts/m1/`、`fixtures/m1/`，保留目录名兼容工程 |
| 工具链 | Python3.12、JDK21（编译目标Java17）、SDK35、AGP8.7.3、Gradle8.10.2；本地PostgreSQL17.11已有验证记录 |
| Android版本 | minSdk26、target/compileSdk35；版本仍为`0.2.0-m2`/code2，M3沿用 |
